- 14ファイルすべて指定URLから HTTP 200 で取得できた（保存先: `data/raw/`）。
- 文字コードはすべて **Shift_JIS(CP932)、BOMなし**。UTF-8 では読めない。

### 鳥獣出没（クマ）の詳細
- 対象は **クマのみ**（種別はすべて「クマ出没箇所」）。鳥獣全般ではない。
- 日付は和暦文字列（`R7.4.7`〜`R8.3.28`）。令和7年度分で止まっており、調査日（2026-10）時点で約6か月古い。
- 時間は `午後１時頃`、`正午頃` など自由記述（全角混在）。
- 座標あり76件。座標なしは「地区」名（例: 荒沢(下田)）のみで住所がなく、推測補完しない（依頼どおり除外）。
- 地図に出せるのは約76件のため、画面に「最新ではない・一部のみ表示」と明記する。
- 重複（地区+座標）38件。同一箇所に複数日の出没がある可能性が高く、重複扱いではなく別イベントとして保持する。

## 3. ジオコーディングの要否
座標を持たない住所のみのデータはない。**ジオコーディングは不要**。クマ出没の座標欠損は住所自体がないため補完不可。

## 4. 品質上の問題と変換時の方針
| 問題 | 方針 |
|---|---|
| CP932・2行ヘッダー | 自動判定してUTF-8化、ヘッダー行を自動検出 |
| 公衆トイレの列名ずれ | ファイル専用のマッピング（name=地区名+公衆トイレ、address採用） |
| 全角数字 | 住所・管理番号などは半角化（名称は原則そのまま） |
| 範囲外・欠損座標 | 出力せず除外件数と該当行を変換ログに記録。`docs/coord-issues.md` に市への報告用リストを出力 |
| 介護の重複 | 名称+座標で集約し、サービス名は併記 |
| 和暦 | `R7.4.7` → `2025-04-07` に変換（`R8`=2026） |
| 緯度の末尾カンマ | 自動補正はせず除外（誤補正を避ける） |
